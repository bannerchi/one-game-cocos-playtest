# Cocos ten-mission public playtest

Ten offline Cocos Creator 3.8.8 prototypes: Power Crates, Signal Link, Chip Memory, Relay Stack, Circuit Flow, Bolt Sort, Pulse Echo, Archive Scan, Signal Filter and Drone Dash.

English-first with nine selectable interface languages. Use the arrows above the mission cards to browse three pages. The six new missions support D1–D3 through the header button. This version tests mobile visuals and controls; PvP equipment, accounts and rewards are not connected.

Font: Hacker Pixel Playtest, a licensed renamed subset of Fusion Pixel 12px Monospaced Simplified Chinese, release 2026.09.01. See [font notices](licenses/FONT-NOTICE.txt) and [SIL OFL](licenses/OFL.txt).

Only compiled preview files are published. No backend, signing material, environment files or source maps.
